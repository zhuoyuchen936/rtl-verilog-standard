# 07 · 数据通路：位宽、符号与运算

位宽 bug 是 RTL 里**最安静**的一类错误：不报错、不告警（除非开了 lint）、
仿真波形看上去也很正常，直到某个边界值把高位截掉。
Verilog 的位宽与符号规则相当反直觉，这一篇就是把这些规则摊开讲。

---

## 本篇速览

1. **表达式的位宽由上下文决定**，包括左值——`assign y8 = a4 + b4;` 里加法是按 8 bit 算的。
2. 混合 signed 和 unsigned 的算术与关系比较要确认共同类型。拼接、切片和移位量各有自己的类型规则。
3. 无尺寸整数常量至少占 32 位，可能扩大中间表达式。SV 的 `'0` 和 `'1` 按上下文定宽。
4. **拼接 `{}` 和移位的右操作数是自定宽度的**，不受上下文影响——这是最常被忽略的例外。
5. 赋值两侧位宽必须显式相等；要截断/扩展就**明写出来**，让读者看见你是故意的。

---

## 一、位宽推导

### R-07-01 表达式位宽由"上下文"决定，左值也参与 `[通用]`

Verilog 先把表达式里所有**上下文决定（context-determined）**的操作数、连同赋值左值一起，
取最大位宽，然后**按这个位宽做整个运算**。

```verilog
wire [3:0] a, b;
wire [4:0] sum5;
wire [3:0] sum4;

assign sum5 = a + b;   // 按 5 bit 运算 -> 进位保留，sum5[4] 是进位
assign sum4 = a + b;   // 按 4 bit 运算 -> 进位丢失（这常常正是 bug）
```

> 注意左值的类型：`assign` 是**连续赋值，只能驱动 net（`wire`）**。
> 对 `reg` 用 `assign` 在纯 Verilog 下是编译错误
> （`verilator --language 1364-2001` 会报 `CONTASSREG`，并直接点名 IEEE 1364-2005 §6.1）。
> `reg` 只能在 `always` / `initial` 这类过程块里被赋值。

**这意味着**：想拿到进位，就把左值开宽一位；`{carry, sum} = a + b;` 也可以，
因为拼接的左值总宽度是 5。

### R-07-02 自定宽度（self-determined）的三个例外 `[通用]`

以下位置**不受上下文影响**，按自身宽度计算，是最容易踩的坑：

| 位置 | 说明 |
|---|---|
| 拼接 `{}` 的每个操作数 | `{a, b}` 中 a、b 各按自身宽度 |
| 重复拼接的重复次数 | `{N{x}}` 的 N 必须是常量 |
| 移位运算的**右**操作数 | `a << b` 中 b 自定宽度（左操作数 a 仍是上下文决定） |

```verilog
wire [3:0] a, b;
wire [7:0] y_bad, y_ok;

assign y_bad = {a + b};   // 拼接内部按 4 bit 算，进位丢了，再零扩展到 8
assign y_ok  = a + b;     // 这才是按 8 bit 算
```

**结论**：不要用 `{}` 去"扩展位宽"，它不会把运算宽度带进去。要扩展就显式写。

### R-07-03 无尺寸整数常量至少 32 位 `[通用]`

普通无尺寸十进制常量带符号，无尺寸有基数的常量默认无符号。数据通路的常量写明宽度、符号和进制。

```verilog
reg [7:0] cnt;
// 右边按 32 bit 算，再截断回 8 bit 存进 cnt。多数时候结果碰巧对，
// 但它掩盖了你的真实意图，而且 lint 会报 WIDTHTRUNC。
always @(posedge clk) cnt <= cnt + 1;

// 推荐：位宽写全，意图明确，lint 干净
always @(posedge clk) cnt <= cnt + 8'd1;
```

`[SV]` 可以写 `cnt + 1'b1`，或用 `'0` / `'1` 这类上下文自适应字面量。

### R-07-04 所有字面量写全位宽与进制 `[通用]`

`8'd0` / `4'b1010` / `16'hDEAD`。不要裸写 `0`、`1`。
参数化模块里用 `{WIDTH{1'b0}}` 或 `{{(WIDTH-1){1'b0}}, 1'b1}` 构造合适宽度的常量。

## 二、符号

### R-07-05 一个无符号操作数就让整个表达式变无符号 `[通用]` ★高频 bug★

```verilog
reg signed [7:0] s;
reg        [7:0] u;

// s 是有符号的，但 u 是无符号的 -> 整个比较按无符号做
// s = -1 时按 8'hFF = 255 比较，对任意已知 8 位 u 都为假
if (s < u) ...

// 正确：显式统一符号
if (s < $signed({1'b0, u})) ...
```

### R-07-06 `reg [N:0]` 默认是无符号的 `[通用]`

要有符号必须写 `reg signed [N:0]`（`[SV]` 用 `logic signed`）。
端口同理：`input signed [7:0] a`。

一个经典陷阱：

```verilog
reg [7:0] a;
if (a - 1 >= 0) ...      // 恒为真：无符号数永远 >= 0
```

`a = 0` 时 `a - 1` 到底等于多少？按 R-07-03，字面量 `1` 是 **32 位**的，
所以整个表达式按 32 位无符号计算，结果是 **4294967295**，不是 255。
想要 8 位回绕（得到 255），必须把字面量的位宽也写成 8 位：

```verilog
wire [7:0] am1_32 = a - 1;      // 32 位算完再截断，中间值是 4294967295
wire [7:0] am1_8  = a - 8'd1;   // 全程 8 位，a=0 时得到 8'd255
```

两种写法**最终存进 8 位变量的结果相同**，但中间表达式的宽度不同——
一旦这个中间值参与比较（就像上面的 `>= 0`）或再拼接，差别就会暴露出来。

### R-07-07 有符号数的位宽扩展要用 `$signed` 或显式符号位复制 `[通用]`

```verilog
wire signed [7:0]  a;
wire signed [15:0] b1, b2, b3;

assign b1 = a;                        // 上下文决定 + a 有符号 -> 自动符号扩展，OK
assign b2 = $signed({{8{a[7]}}, a});  // 显式写法，最不容易看错
assign b3 = {{8{a[7]}}, a};           // 位模式对，但拼接结果是无符号的！
```

右侧拼接表达式是无符号的。赋给声明为 signed 的 `b3` 后，后续直接使用 `b3` 按它的声明取类型。把拼接直接放进有符号算式时，先显式转换。

## 三、运算与可综合性

### R-07-08 正 2 的幂除数、符号和舍入 `[通用]`

无符号整数除以 8 的商可用 `u >> 3`，余数可用 `u[2:0]`。Verilog 的有符号整数除法向零截断，非零余数跟随被除数的符号。对 signed 左操作数，`>>>` 向负无穷舍入，`>>` 高位补零。8 位 `a=-9` 时，`a / 8'sd8` 为 −1，`a >>> 3` 为 −2，`a >> 3` 为 30。`a % 8'sd8` 为 −1，低三位为 7。

若目标是精确的向零商和余数，直接写带符号的常数除法是一个候选。另一个候选对负数先加偏置，再做算术右移。以下片段使用 8 位 unsigned 输入 `u`、8 位 signed 输入 `a` 和正除数 8。

```verilog
wire [7:0] unsigned_q = u >> 3;
wire [2:0] unsigned_r = u[2:0];
wire signed [8:0] wide_a = {a[7], a};
wire signed [8:0] biased = wide_a + (a[7] ? 9'sd7 : 9'sd0);
wire signed [8:0] quotient = biased >>> 3;
wire signed [8:0] remainder = wide_a - (quotient <<< 3);
```

若规格要求最近偶数舍入、饱和或逐级截断，写明发生位置，按独立参考检查中点、符号边界与溢出。变量除数另约定除零和最小负数除以 −1 的结果及状态。

### R-07-09 变长移位比想象中贵 `[通用]`

W 位数据允许 0 到 W−1 的可变移位时，典型桶形结构有 ⌈log₂ W⌉ 级，每级至多 W 个二选一选择器。移位量只有几种合法值时，可比较受限选择器与通用结构。对超宽移位量保留规格规定的越界结果。实际 LUT、布线和标准单元面积以目标映射为准。

### R-07-10 变量索引的位选用 indexed part-select `[V2001]`

```verilog
// 反例，不要抄：位选的上下界都必须是常量，这样写编译不过
assign y = data[i*8+7 : i*8];

// 正例：indexed part-select，起点可变、宽度是常量
assign y = data[i*8 +: 8];   // 从 i*8 向上取 8 位
assign y = data[i*8 -: 8];   // 从 i*8 向下取 8 位
```

宽度必须是常量；起点可以是变量。教材 p.381 可综合(15) 也提醒过：
大量使用动态指针索引会综合出很多门且难以优化。

### R-07-11 位宽相关的 lint 告警不许豁免 `[工具]`

Verilator 的 `WIDTHTRUNC` / `WIDTHEXPAND` 是最有价值的两条规则。
它们几乎总是指向真问题，或至少指向"意图不明确"。
如果确实要截断，请显式写出来，让告警自然消失：

```verilog
assign y8 = a16[7:0];              // 明写截断，不是让工具替你截
assign y16 = {8'd0, a8};           // 明写零扩展
assign y16 = $signed(a8);          // 明写符号扩展（a8 须为 signed）
```

## 四、流水线与面积/速度取舍

### R-07-12 拆流水线是打断长组合链的首选手段 `[通用]` `[教材]` p.149-154

在时序报告指向的组合链中选切点。以时钟拍数分别记录首结果延迟 L、可连续接收新输入的最小间隔 II、停顿时在途容量。前馈流水增加 L 后仍可达到 II=1。累加反馈、共享端口或队列回压可能增大实际发射间隔。寄存数据时对齐 valid、标签和边带。

```verilog
// 自由运行、每拍均可推进的固定延迟流水
always @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
        s1_valid <= 1'b0;
        s2_valid <= 1'b0;
    end else begin
        s1_valid <= in_valid;
        s2_valid <= s1_valid;
    end
end
always @(posedge clk) begin
    s1_data <= f(in_data);
    s2_data <= g(s1_data);
end
```

注意上面第二个块**没有复位**——这是 R-06-07 允许的数据通路豁免，
前提是 valid 链有复位（第一个块），数据在 valid 为 0 时不会被下游使用。可停流水需要让有效位和载荷使用相同的逐级推进条件。自由运行的算子若接入可背压出口，应在接收输入时为其在途结果预留足够的输出槽位。

### R-07-13 资源共享不要凭猜测 `[通用]` ⚠️

流传很广的说法是"把互斥的算子写进同一个条件表达式，综合器就会共享它们"，
例如 `y = sel ? (a*b) : (c*b);` 会共享一个乘法器。

**但这条在调研中找不到可移植的一手依据**——不同综合器、不同选项下行为不同。
本规范的态度：**不要在 RTL 里靠写法去"暗示"资源共享**。
需要控制资源时，用综合报告实测（`report_utilization` / `report_resources`），
或直接把共享的算子显式提取成一个实例：

```verilog
// 显式共享：只有一个乘法器，谁用它由 MUX 决定
wire [15:0] mul_a = sel ? a : c;
wire [31:0] product = mul_a * b;
```

这样意图写在代码里，不依赖工具的推断。

### R-07-14 按精度、带宽和 II 选算子

先从接口确定操作数范围、Q 格式、精确或允许近似的结果、并列值的处理、舍入与饱和的位置。再列目标时钟、L、II、每次发射所需的新操作数与写回数。固定点积可从全精度乘积开始，对 K 项求最坏和并计入 bias。例：32 项 signed INT8 乘积同时取 `(−128)×(−128)`，和为 524,288，带符号累加器至少需要 21 位才能容纳这个正端点。若要窄化，可用真实输入界证明或按获准的误差预算评估。

| 算子 | 可比较的结构 | 选择依据与核验 |
|---|---|---|
| 点积、卷积、MAC | 复用 MAC、并行乘法加平衡归约树、目标 DSP 的乘加级联 | 低发射率可复用并计入仲裁与操作数 MUX。高吞吐先核对乘法位宽、累加反馈距离、级联方向及存储供数。连续独立输出可交织多个累加上下文，须核对标签和最后一项的写回。 |
| sum、max、argmax | 逐拍归约、分组归约、分级树 | 结合律取决于数值合同。浮点舍入和逐级饱和会改变求和结果。argmax 要保留并列索引的取舍。比较树插拍后对齐值、索引与尾组掩码。 |
| 除法、倒数 | 常数化简、有限域精确查表、逐拍迭代、展开流水 | 区分商与余数、向零与其他舍入。小输入域可按表项数与读口估价。低调用率可迭代，高发射率要核对迭代单元的 II。以倒数乘法替代整除时覆盖商边界，按合同添加修正或记录误差。 |
| exp、激活、归一化 | 有限域 ROM、范围缩减加分段近似、共享或复制流水 | 核对饱和端、分段边界、系数量化和中间位宽。归一化还需安排统计量、倒数和重读端口。允许近似时保留原参考，报告独立模型上的逐层误差，并在有真值的样本上报告任务指标。 |

用同一负载记录 accepted、issued、returned 及等待拍数，确认调度、返回端口或背压是否限制收益。硬件资源以同器件、时钟、配置、层次与实现阶段的报告比较。[存储端口选型](09-memory-and-primitives.md#r-09-11-按实际访问选择存储结构)
